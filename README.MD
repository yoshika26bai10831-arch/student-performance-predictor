# Student Performance Predictor

## Project Description

Student Performance Predictor is a Python-based project that analyzes student information and predicts their performance level.

## Features

-Takes student name as input
-Takes study hours
-Takes attendence percentage
-Takes previous marks
-Takes assignment marks
-Takes internal marks
-Calculate total marks
-Calculate average marks
-Predicts performance
-Provides a suggestion
-Saves student data in CSV format

## Technologies Used

-Python
-CSV
-Command Prompt
-GitHub

## Project Files

-main.py-Main Python program
-student.csv-Student performance data
-README.md-Project program

## How to Run

Open Command Prompt inside the project folder and type:

python main.py

Then enter the student details when asked

## Output

The program displays:

-Total Marks
-Average Marks
-Performance
-Suggestion

## Conclusion

This project helps understand python programming, functions, CSV file handling, conditional statements, and basic student performance analysis
